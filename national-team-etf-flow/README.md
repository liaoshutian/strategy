# 宽基 ETF 持仓水位

[线上看板](https://liaoshutian.github.io/strategy/national-team-etf-flow/dist/) · [参考报表与数据来源](https://wwww1998.github.io/national-team-etf-flow/)

这是独立实现：只从原报表读取数值和基金/指数标识，不复制其页面或代码，不运行上游脚本。页面、Git 存储和发布由本仓库维护。上游数据暂未发布时，已发布页面继续显示最后一次有效观测日；不是独立的交易所抓取服务。

## 口径
- 金额统一为人民币亿元，基金份额为亿份，日期按北京时间。持仓金额是原报表样本的份额乘单位净值加总，涵盖全部持有人；也会随净值涨跌。净申赎是份额变动乘当日单位净值的估算，不是汇金实际成交。不把两者混用。
- 采用原报表的最长持仓序列，原站历史覆盖不均，不宣称全历史每一天都有当前篮子的全部品种。原站公布的缺失持仓值以空值呈现，不填零；原站已汇总的净申赎按发布口径采用，不据此判断底层每只基金都完整。篮子成员改变时暂停自动更新，需先审查新旧口径，不能直接把两个篮子的峰值混用。
- MA10/20/30/60/200 是最近 N 个交易日持仓金额的简单平均，含数据日，完整窗口才计算。同一图表显示 MA 与原线，下表用当前持仓逐一除以各 MA 及全历史峰值；超过均线可大于 100%。峰值相同时显示首次日期，缩放不改变计算。
- 近一周（5 个交易日）或近一月（21 个交易日）加仓力度 = 同窗口全市场净申赎 / 全历史持仓峰值 × 100%，不是持仓金额的涨幅。正为净申购，负为净赎回。缺乏数据不作零；不做收益或仓位建议。
- 保留日净申赎、指数 K 线与资金流联动、ETF 汇总及近 10 日明细。K 线有缺项不补前值。

## 运行、验证和发布
```sh
cd national-team-etf-flow
python tools/update.py
python -m unittest discover -s tools -p 'test_*.py'
node --test test.mjs
python -m http.server 8000 --directory dist
```
- Actions 北京时间周一至周五 16:13、周二至周六 00:24，以及周一至周六 09:37 补查。节假日或同一有效数据不产生 Git 提交。可以手动 Run workflow，并可用 `--input` 复核保存的公开源报表（原始响应不提交）。
- 日期、缺值、代码、格式或历史校验失败时 Actions 标红，不覆盖上次有效数据或部署；修好源或适配器后手动重跑。只提交校验后的 `dist/data/` 数值快照，检测并发分支更新，不强推。
- 和风险溢价看板共用 GitHub Pages；两个工作流均用同一组装脚本和并发组。更新 Git 后由同一 workflow 明确发布，避免 Actions 的推送不能触发下一个 workflow。
