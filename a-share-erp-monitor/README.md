# 股债风险溢价看板
一个无第三方 JS、无后端的独立项目，交互参考 [科技红轮动看板](https://github.com/wwww1998/rotation-monitor)，未复制其代码或修改原项目。

运行：`python3 -m http.server 8080 --directory dist`，然后打开 http://localhost:8080 。直接 file:// 打开时部分浏览器会禁用模块加载。测试：`node --test verify.mjs`。部署使用 dist 静态目录。

- Wind 模式保留 2026-11-20 Wind/半夏图表快照。中证1000 1.24 pp、95.6%；中证500 2.17 pp、87.57%；沪深300 5.84 pp、72.41%。三个指数的原图阈值、中位数和其他可读统计均按半夏转载图记录。不从读数截图反推完整历史；未核字段留空，不随自动数据更新。
- 导入 UTF-8 长表 `date,code,pe_ttm,bond10y_pct,close`（最后一列可选）。每个交易日与指数组合一行，国债日期为同日，收益率用百分数数值（1.58 表示 1.58%），PE 正数，非正/缺失观测应省略。只接受三个指数及 Excel 数字代码或 .SH 后缀。源序列与 Wind 快照分开；数据不上传，浏览器有空间时保存在本地。
- 股债利差 = 100 ÷ PE-TTM − 十年国债收益率（百分点）。历史分位只使用同一数据源截至观测日期的样本，窗口内同值按半权重。原图自报分位与导入重算分位分开。横轴预设、直接日期选择和手动缩放只影响画面；样本窗口单独选择。图上缺口超过 7 日不会连线。阈值只用于视觉标记，不据此下单，不将分位解释为胜率。
- 图表中叠加三指数风险溢价；选中指数可添加右轴价格。导出所见时间和指数的数据，不伪造缺失值。阈值模式和指数独立保存，可拖动线或滑块修改。

资料：Wind 截图的公开转载链接、中证指数官网及中债曲线链接见看板。中债曲线可能与原图中证国债序列不同。

### 分开导出的两份 CSV

如市盈率和国债收益率是两份已获准使用的 UTF-8 CSV，可在本地按同一自然日合表：

```sh
python3 tools/merge_csv.py index.csv bond.csv erp-history.csv
```

指数表使用 `date,code,pe_ttm,close`（收盘可省略），债券表使用 `date,bond10y_pct`（例如 `1.58` 或 `1.58%`）。脚本不访问网络，不用昨日国债值填补缺口，遇重复键报错，输出必须是新文件。把输出导入看板即可。不要混用不同口径的历史市盈率或不同收益率曲线。


## 自动更新与发布

- [风险溢价 · 中证数据更新与发布](../.github/workflows/erp-update.yml) 在工作日北京时间 19:17 跑一次，21:43 再检查，也可在 Actions 点击 Run workflow。调度时间可能延迟。只在 CSV 实际变化时提交，成功部署后按实际交易数据日展示；手动触发即使无差异也可重新发布。失败保留已有提交，不用其他曲线、估值数据或 Wind 快照填补缺项。
- `tools/update_csi.py` 从中证指数官网的指数表现接口取三个指数的滚动市盈率 `peg` 及 `close`，从[基金业协会中证产品页](https://www.amac.org.cn/sjtj/fwjgxxjcp/zzzs/)对应接口取中证国债到期收益率曲线 `Treasury Bond Term Structure` 的 10 年点。仅做同日匹配，日期按北京时间解读；三个指数和 10 年点齐备才写入 `dist/data/csi.csv`。数据使用与再发布须符合来源授权，不提交原始接口响应或私有数据。
- 首次默认拉最近 45 个自然日；之后覆盖最近已知观测日往前 9 天至最新可查日期，以补齐错过的日子及修订。近月以外的历史可在有权使用时指定 `start_date` 与 `end_date` 分段回填；每次相差不超过 366 天，历史补录不覆盖区间之外的数据。页面不补缺口、不把样本区间冒充完整 Wind 历史。
- 本地校验：`python -m unittest discover -s tools`、`node --test verify.mjs`。本地刷新：`python tools/update_csi.py`，可加 `--start YYYY-MM-DD --end YYYY-MM-DD`。测试使用模拟上游，不向 Git 写入。Pages 需选择 GitHub Actions 发布源；本 workflow 直接部署制品，不依赖 bot commit 触发另一条 workflow。
