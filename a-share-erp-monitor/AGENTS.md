# A 股风险溢价看板维护规范

继承仓库根目录的 [AGENTS.md](../AGENTS.md)，以下为本策略约定。

- 工作流在仓库根目录 `.github/workflows/erp-update.yml`；工作日北京时间 19:17 更新、21:43 复查，支持手动运行。观察日按北京时间和上游实际发布记录判断。初次拉近 45 个自然日；日常在上次观测日前 9 天开始重查，人工补录需明确起止。
- 使用中证指数官网 `peg`（滚动市盈率）和收盘点位；基金业协会中证曲线的国债到期收益率 10 年点。按同一观测日合并，分别验证沪深300（000300）、中证500（000905）、中证1000（000852）。收益率数值 1.58 表示 1.58%，利差为 `100 / pe_ttm - bond10y_pct` 个百分点。
- 任务只允许自动提交 `dist/data/csi.csv`。同日三指数和国债均通过校验才写；字段变化、部分缺报、既有交易日突然消失或非 JSON 响应均不得提交。无变化不造提交。与 Wind 原图和本地 CSV 隔离，不继承 Wind 阈值；不缓存原始响应或凭证。
- 校验命令：`python -m unittest discover -s tools`、`node --test verify.mjs`。先核对 Actions 中抓取、提交和部署的独立状态，再核对 Git 与 Pages 上 CSV 最新观测日是否一致。部署失败可手动重跑，即使 Git 无差异仍能部署。
